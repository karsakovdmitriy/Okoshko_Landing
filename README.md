# Лендинг «Окошко»

Современный лендинг для экосистемы «Окошко» (онлайн-запись и автоматизация). Построен на Next.js 15, Tailwind CSS и Supabase.

## Инструкция по настройке базы данных и деплою

Проект использует Supabase для хранения контактов. Для работы необходимо настроить таблицу, отключить или настроить RLS (Row Level Security) и подключить API ключи.

### 1. Создание таблицы в Supabase

1.  Создайте проект на [supabase.com](https://supabase.com).
2.  Перейдите в раздел **SQL Editor**.
3.  Выполните следующий запрос для создания таблицы `contacts`:

```sql
create table contacts (
  id bigint generated by default as identity primary key,
  name text not null,
  email text not null,
  phone text not null,
  created_at timestamp with time zone default timezone('utc'::text, now()) not null
);
```

### 2. Настройка безопасности (RLS)

По умолчанию Supabase блокирует все запросы к новым таблицам. Чтобы форма на лендинге могла сохранять данные, выполните **один** из следующих шагов в SQL Editor:

**Вариант А: Разрешить анонимную вставку (Рекомендуется)**
Создает политику, которая позволяет любому пользователю с Anon Key добавлять записи:
```sql
alter table contacts enable row level security;

create policy "Allow anonymous inserts"
on contacts for insert
to anon
with check (true);
```

**Вариант Б: Полностью отключить RLS (Простой путь)**
```sql
alter table contacts disable row level security;
```

### 3. Настройка переменных окружения

Вам понадобятся **Project URL** и **Anon Key** из раздела **Settings** -> **API** в вашем проекте Supabase.

#### Локально:
Создайте файл `.env` в корне проекта:
```env
NEXT_PUBLIC_SUPABASE_URL="ваш_project_url"
NEXT_PUBLIC_SUPABASE_ANON_KEY="ваш_anon_key"
```

#### На Vercel:
Перейдите в настройки проекта: **Settings** -> **Environment Variables** и добавьте обе переменные.

### 4. Деплой на Vercel

1.  Загрузите код в ваш GitHub репозиторий.
2.  Импортируйте проект в Vercel.
3.  Добавьте переменные окружения в процессе импорта.
4.  Нажмите **Deploy**.

## Разработка локально

1.  Установите зависимости:
    ```bash
    npm install
    ```
2.  Настройте `.env`.
3.  Запустите сервер разработки:
    ```bash
    npm run dev
    ```
4.  Откройте [http://localhost:3000](http://localhost:3000).

## Технологический стек
*   **Frontend:** Next.js (App Router), React 19, Tailwind CSS, Lucide-React.
*   **Backend:** Next.js Serverless Functions + Supabase JS Client.
*   **Database:** PostgreSQL (via Supabase).
